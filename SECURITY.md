# Security

Follow the [ANS security policy](https://github.com/agentnameservice/governance/blob/main/SECURITY.md)
for vulnerability handling, response targets, and coordinated disclosure.

To report a vulnerability in this repository, use
[Report a vulnerability](https://github.com/agentnameservice/ans-registry/security/advisories/new)
in its Security tab. Do not include vulnerability details or credentials in a
public issue, pull request, or discussion.

## Affected versions

For specification reports, include the affected document version or commit
and the requirement or example that causes the vulnerability. The
[ANS security policy](https://github.com/agentnameservice/governance/blob/main/SECURITY.md)
describes coordination with affected implementations.
